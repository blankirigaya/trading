# FYERS API V3 market data

FYERS is the **market data provider** only. Nothing in this package places, modifies, or cancels
an order. Execution is `PaperBroker`, inside the application.

## Modules

| File | Responsibility |
| --- | --- |
| `auth.py` | Credentials, `<app_id>:<access_token>` headers, `hsm_key` claim extraction, symbol-token lookup. Redacts secrets from `repr`. |
| `protocol.py` | Binary wire protocol: envelope framing, field schemas, frame builders, parsers. |
| `client.py` | Data-socket session: auth, channel, subscribe, flow-control ack, reconnect, resubscribe. |
| `instruments.py` | FYERS symbol parsing (`NSE:INFY-EQ`) and internal `Instrument` identity. |
| `normalizer.py` | Wire data to `MarketTick`, `Candle`, `MarketState`; raw payload preservation. |
| `market_data.py` | Per-instrument `MarketState` accumulation and mark prices. |
| `historical.py` | OHLCV retrieval over REST. |
| `feed.py` | Resolves symbols to HSM topics and assembles socket + service. |
| `probe.py` | Connectivity probe and diagnostics. |
| `broker.py` | `FyersBroker`, which exists only to raise on every trading method. |

## Wire protocol

The FYERS V3 Data WebSocket (`wss://socket.fyers.in/hsm/v1-5/prod`) is **binary, not JSON**.

```text
envelope:  [2B BE u16 data_len] [1B req_type] [1B field_count]
           { [1B field_id] [2B BE u16 len] [bytes] } * field_count

datafeed:  req_type 0x06, then BE u32 message_num, BE u16 scrip_count,
           then per scrip: [1B data_type][2B topic_id][1B name_len][name]
                           [1B field_count][field_count * BE i32]
```

Price fields are big-endian `i32` scaled by 100. Per-scrip data types are `0x53` snapshot, `0x55`
update, and `0x4c` lite. `protocol.py` field ordering follows the reference `fyers_apiv3` SDK's
`map.json` (`data_val`, `lite_val`, `index_val`).

**FYERS does not publish a packet-structure specification.** This implementation follows the
reference SDK layout and the documented HSM builders, and is verified offline against known
vectors in `tests/unit/test_fyers_protocol.py`. It has not yet been validated against a live feed.
Re-verify the constants if the upstream schema changes.

## Flow control

The server publishes an `ack_count` in field 2 of the auth response. The client echoes the latest
datafeed `message_num` every `ack_count` frames; without this the server stops emitting updates.

## Security

Credentials come from settings only. `FyersAuth.__repr__` redacts them, probes never print them,
and the access token is stored nowhere. Extract the `hsm_key` claim from the token JWT for socket
authentication; the token itself is only used in the authorization header.

## Testing

Binary fixtures in `tests/fixtures/` are generated by `tests/fixtures/build_fyers_fixtures.py`
using the production protocol builders. Regenerate with:

```bash
uv run python tests/fixtures/build_fyers_fixtures.py
```
